# Asset License Registry

All assets used by Project Earth must be free/open-source compatible, original, public domain, or otherwise legally usable at Rs.00 direct spend. Add an entry before importing any third-party asset into the game, admin panel, website, trailer, or documentation.

## Required Fields

| Field | Description |
| --- | --- |
| Asset ID | Stable internal ID used by the project |
| Asset name | Human-readable name |
| Type | Model, texture, sound, music, font, icon, map data, script, shader, etc. |
| Source URL | Original download/source page |
| Author | Creator name or organization |
| License | Exact license name and version |
| Attribution required | Yes/No and required text |
| Modified | Yes/No and description of changes |
| Imported path | Repository path after import |
| Reviewed by | Person who checked license compatibility |
| Review date | Date reviewed |
