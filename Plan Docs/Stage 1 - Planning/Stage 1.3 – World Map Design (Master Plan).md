# Stage 1.3 – World Map Design (Master Plan)

## Step 1 — Map Philosophy

Instead of creating one huge map immediately, we'll create a **hierarchical world**.

```
Planet
 ├── Continents
 │     ├── Countries
 │     │      ├── States
 │     │      │      ├── Cities
 │     │      │      │      ├── Districts
 │     │      │      │      │      ├── Roads
 │     │      │      │      │      ├── Buildings
 │     │      │      │      │      └── NPCs
```

This structure makes the game easier to expand over time.

---

# Step 2 — World Scale

We'll target an Earth-like distribution:

* 🌊 ~70% Oceans
* 🏝️ ~30% Land
* 8 Continents
* 60–100 Countries
* 800+ Cities (added gradually)
* Thousands of villages
* Millions of procedural trees, rocks, and props

Only a small part of this world will exist in the first playable version.

---

# Step 3 — Geographic Layers

We'll design the map in layers:

1. Coastlines
2. Mountains
3. Rivers
4. Lakes
5. Climate zones
6. Forests
7. Roads
8. Railways
9. Airports
10. Seaports
11. Cities
12. Villages
13. Landmarks

This layered workflow is commonly recommended in worldbuilding because geography naturally influences climate, settlements, transport, and economies. ([Worldbuilding Stack Exchange][1])

---

# Step 4 — Free Resources

For references and planning:

* **OpenStreetMap** — Open road, building, and place data.
* **Natural Earth** — Public-domain coastlines, rivers, terrain, and boundaries.
* **Google Earth** — Visual reference for studying real geography. Use it for inspiration and measurements, but don't copy or redistribute its imagery or 3D models. ([medevel.com][2])

For documentation, many solo creators successfully use simple tools like Google Docs or offline note systems such as Obsidian to organize their world. ([Anima][3])

---

# Step 5 — Region Naming Rules

We'll establish naming conventions before creating places.

For example:

* Northern regions → shorter, colder-sounding names.
* Tropical islands → softer, flowing names.
* Desert regions → stronger consonants.
* Coastal cities → names inspired by harbors or bays.

Consistent naming makes the world feel believable.

---

# Step 6 — Transportation Skeleton

Before placing buildings, we'll define:

* International highways
* Rail corridors
* Shipping routes
* Flight corridors
* River transport

Real cities tend to grow around transportation networks, so we'll mirror that design logic.

---

# Step 7 — Landmark Categories

We'll maintain a checklist of landmark types so each region feels unique.

Natural:

* Mountains
* Waterfalls
* Volcanoes
* Caves
* Lakes
* Forests
* Deserts

Human-made:

* Airports
* Stadiums
* Universities
* Museums
* Dams
* Ports
* Industrial zones
* Shopping districts

---

# Step 8 — Version Roadmap

Instead of trying to build Earth at once:

* **v0.1:** One district
* **v0.2:** One town
* **v0.5:** One complete city
* **v1.0:** One region with countryside
* **v2.0+:** Additional regions and countries

This keeps the project achievable for a solo creator.
